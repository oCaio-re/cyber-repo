Roadmap de Cibersegurança

Um plano de 12 meses, com cerca de 8 a 10 horas por semana, que vai de "nunca abri um terminal" até ter um portfólio com projetos de ataque e defesa. Cada fase tem três partes: o que estudar, exercícios práticos (marque conforme concluir, o progresso fica salvo neste navegador) e um projeto para colocar no GitHub.

Antes de começar: monte seu laboratório

Todo o treino prático acontece em máquinas suas ou em plataformas feitas para isso. Reserve a primeira semana para deixar o ambiente pronto.

Ambiente local

  • Hipervisor: VirtualBox ou VMware Workstation (gratuitos). Você já usa Linux, então KVM/virt-manager também serve.
  • VM atacante: Kali Linux ou Parrot OS.
  • VMs alvo: Metasploitable 2, OWASP Juice Shop (via Docker), DVWA.
  • Rede: configure uma rede "host-only" ou NAT interna para as VMs vulneráveis nunca ficarem expostas à internet.
  • Snapshots: tire um antes de cada exercício para voltar ao estado limpo.

Contas e ferramentas

  • TryHackMe: trilhas guiadas, ótimo para começar.
  • HTB Academy e Hack The Box: módulos e máquinas mais desafiadoras.
  • PortSwigger Web Security Academy: segurança web, gratuito.
  • GitHub para o portfólio e um app de notas (Obsidian, Notion ou Markdown puro) para seus write-ups.

Regra número um: só teste o que você tem autorização escrita para testar.

No Brasil, invadir dispositivo alheio é crime (Lei 12.737/2012, art. 154-A do Código Penal). Use apenas seu laboratório, plataformas de CTF e programas de bug bounty, respeitando sempre o escopo publicado.

01

Fundamentos de TI

meses 1–2

Objetivo: entender como computadores, sistemas operacionais e redes funcionam. Não dá para proteger ou atacar algo que você não entende.

Estudar

  • Linux: sistema de arquivos, permissões (chmod, chown), usuários, processos, pacotes, grep/find/pipes, SSH.
  • Redes: modelo OSI e TCP/IP, endereçamento IP e sub-redes, TCP vs UDP, portas, DNS, DHCP, HTTP/HTTPS, NAT.
  • Windows: usuários e grupos, registro, serviços, PowerShell básico, Event Viewer.
  • Programação: Python (variáveis, loops, funções, arquivos, requests, socket) e Bash básico.
Recursos Linux Journey TryHackMe: Pre Security Automate the Boring Stuff with Python Cisco NetAcad: Networking Basics

Praticar

Projeto

Scanner de portas em Python

Um script que recebe um IP e um intervalo de portas, testa conexões TCP com socket e mostra as portas abertas. Depois, adicione threads para ficar mais rápido e tente pegar o banner do serviço.

EntregaRepositório no GitHub com README explicando como usar e o que você aprendeu sobre o handshake TCP.
02

Princípios de segurança

meses 3–4

Objetivo: aprender o vocabulário e os conceitos que aparecem em qualquer área da segurança, da tríade CIA ao MITRE ATT&CK.

Estudar

  • Conceitos: tríade CIA, ameaça vs vulnerabilidade vs risco, defesa em profundidade, menor privilégio.
  • Criptografia: hash (SHA-256, bcrypt), criptografia simétrica (AES) e assimétrica (RSA), TLS, certificados, assinaturas digitais.
  • Autenticação: senhas, MFA, OAuth/SSO, como senhas são armazenadas e quebradas.
  • Ataques comuns: phishing, malware, ransomware, engenharia social, força bruta, MITM.
  • Frameworks: MITRE ATT&CK, Cyber Kill Chain, OWASP Top 10, LGPD.
Recursos Professor Messer: Security+ (vídeos gratuitos) TryHackMe: Cyber Security 101 MITRE ATT&CK

Praticar

Projeto

Auditor de senhas

Ferramenta de linha de comando que avalia a força de uma senha (tamanho, entropia, padrões comuns) e consulta a API k-anonymity do Have I Been Pwned para saber se ela já vazou, sem enviar a senha completa.

EntregaCódigo no GitHub e um README explicando por que o k-anonymity protege a senha do usuário.
03

Segurança web

meses 5–6

Objetivo: entender como aplicações web quebram. É a porta de entrada mais comum, tanto para pentest quanto para bug bounty e AppSec.

Estudar

  • Como a web funciona: requisições e respostas HTTP, cookies, sessões, CORS, same-origin policy.
  • OWASP Top 10: controle de acesso quebrado, injeção (SQLi, command injection), XSS, SSRF, falhas de autenticação, configuração insegura.
  • Ferramentas: Burp Suite Community (proxy, Repeater, Intruder), DevTools do navegador, ffuf/gobuster.
  • Defesa: queries parametrizadas, encoding de saída, CSP, validação de entrada.
Recursos PortSwigger: Learning Paths OWASP Top 10 OWASP Juice Shop

Praticar

Projeto

App vulnerável e corrigido

Crie uma aplicação web pequena (Flask ou Express) com login, busca e comentários contendo 3 vulnerabilidades de propósito: SQLi, XSS armazenado e IDOR. Explore cada uma e depois faça um commit separado com a correção.

EntregaRepositório com duas branches (vulnerável e corrigida) e um relatório no estilo pentest: descrição, impacto, passos para reproduzir e recomendação.
04

Blue team: detecção e resposta

meses 7–8

Objetivo: aprender a enxergar ataques nos logs e no tráfego. É onde está a maioria das vagas de entrada (analista de SOC).

Estudar

  • Logs: Windows Event Logs (IDs 4624, 4625, 4688, 4720), Sysmon, logs do Linux (auth.log, journald), logs de servidor web.
  • SIEM: Splunk ou Elastic/Kibana, buscas, dashboards, alertas.
  • Análise de tráfego: Wireshark avançado, Zeek, Suricata/Snort.
  • Resposta a incidentes: ciclo do NIST (preparação, detecção, contenção, erradicação, recuperação, lições aprendidas).
  • Detecção: regras Sigma e YARA, threat intelligence, IOCs.
Recursos TryHackMe: SOC Level 1 CyberDefenders Malware-Traffic-Analysis.net LetsDefend

Praticar

Projeto

Home SOC

Suba o Wazuh ou o Elastic Stack numa VM, conecte um agente Windows (com Sysmon) e um Linux. Simule ataques com o Atomic Red Team e crie alertas e um dashboard que os detectem.

EntregaPost no blog ou README com diagrama da arquitetura, capturas dos alertas e quais técnicas ATT&CK você detectou e quais escaparam.
05

Pentest e CTFs

meses 9–10

Objetivo: juntar tudo numa metodologia de ataque completa, do reconhecimento até o acesso root ou Administrador.

Estudar

  • Metodologia: reconhecimento, enumeração, exploração, pós-exploração, relatório.
  • Enumeração: nmap (-sC -sV), SMB, FTP, SNMP, enumeração web.
  • Exploração: searchsploit, Metasploit, reverse shells, transferência de arquivos.
  • Escalada de privilégio: SUID, sudo, cron, kernel (Linux); serviços, tokens, credenciais salvas (Windows).
  • Active Directory (básico): Kerberos, enumeração com BloodHound, Kerberoasting.
Recursos TryHackMe: Jr Penetration Tester GTFOBins HackTricks IppSec (vídeos de máquinas HTB)

Praticar

Projeto

Portfólio de write-ups e relatório de pentest

Documente cada máquina resolvida num write-up (só de máquinas aposentadas ou com permissão de publicação). Escolha uma delas e escreva um relatório profissional completo: sumário executivo, escopo, achados com severidade CVSS e recomendações.

EntregaBlog (GitHub Pages ou Hashnode) com pelo menos 5 write-ups e o relatório em PDF.

Uma semana típica (cerca de 9 horas)

Constância vale mais que maratona. Uma hora por dia rende mais do que oito horas num sábado a cada duas semanas.

Dicas para não travar

Hábitos

  • Escreva sobre tudo o que resolver. Explicar é o melhor teste de que você entendeu.
  • Fique até 30–45 minutos travado antes de olhar uma dica. Depois disso, olhe só o próximo passo, não a solução inteira.
  • Leia os write-ups de outras pessoas mesmo dos desafios que você resolveu: há sempre um caminho diferente.
  • Aprenda inglês técnico. A maior parte da documentação e das vagas melhores exigem.

Para acompanhar

  • Podcasts: Darknet Diaries, Security Now, Segurança Legal (em português).
  • Notícias: The Hacker News, BleepingComputer, Krebs on Security.
  • Livros: The Web Application Hacker's Handbook, Practical Malware Analysis, Blue Team Handbook.
  • Canais: John Hammond, NetworkChuck, IppSec, Papo Binário (em português).
